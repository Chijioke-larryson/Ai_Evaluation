# Sample research report — illustrative example

This document is a template example only. It is not evidence that any tool was tested, and it contains no real benchmark result.

## Question

Which AI-assisted workflow might help a small software team draft Python test cases?

## Method

Record the exact prompt, provider, task category, generated response, predefined test results, reviewer observations, and limitations. Repeat the same task across tools before making a recommendation.

## Illustrative observation

An assistant might produce a useful first draft quickly, but the team would still need to inspect edge cases, security implications, and maintainability. This is a hypothesis until measured with saved experiments.

## Recommendation

Pilot the workflow on non-sensitive code, require human review, and track test pass rate and review effort over several equivalent tasks.
